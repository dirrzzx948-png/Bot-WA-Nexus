🤖 Bot-WA-Nexus

Bot WhatsApp berbasis Node.js yang dapat digunakan untuk menjalankan berbagai fitur dan perintah otomatis melalui WhatsApp.

📲 Instalasi Termux (Android)

Pastikan sudah menggunakan Termux.

Jalankan satu perintah berikut:

pkg update -y && pkg upgrade -y && pkg install nodejs git ffmpeg -y && git clone https://github.com/dirrzzx948-png/Bot-WA-Nexus.git && cd Bot-WA-Nexus && npm install && npm start

🪟 Instalasi Windows

Pastikan sudah terinstall:

- Node.js 18 atau lebih baru
- Git
- FFmpeg

Buka CMD / PowerShell, lalu jalankan:

git clone https://github.com/dirrzzx948-png/Bot-WA-Nexus.git
cd Bot-WA-Nexus
npm install
npm start

Atau langsung satu perintah di PowerShell:

git clone https://github.com/dirrzzx948-png/Bot-WA-Nexus.git; cd Bot-WA-Nexus; npm install; npm start

▶️ Menjalankan Bot

Setelah instalasi selesai, untuk menjalankan bot kembali:

Termux:

cd Bot-WA-Nexus && npm start

Windows:

cd Bot-WA-Nexus
npm start

🔐 Keamanan

Jangan membagikan QR/kode pairing, session, credentials, API key, atau file autentikasi kepada orang lain.

Gunakan bot dengan bijak dan jangan digunakan untuk spam atau aktivitas yang mengganggu pengguna lain.

❗ Troubleshooting

Jika muncul error saat menjalankan bot, coba:

npm install
npm start

Pastikan Node.js sudah terinstall dengan benar:

node -v

Jika menggunakan Windows, pastikan Git dan FFmpeg sudah masuk PATH agar dapat dipanggil melalui CMD/PowerShell.
