🤖 Bot-WA-Nexus

Bot WhatsApp berbasis Node.js yang dapat digunakan untuk menjalankan berbagai fitur dan perintah otomatis melalui WhatsApp.

📲 Instalasi Termux (Android)

Pastikan sudah menggunakan Termux.

Jalankan satu perintah berikut:

```bash
pkg update -y && pkg upgrade -y && pkg install nodejs git ffmpeg -y && git clone https://github.com/dirrzzx948-png/Bot-WA-Nexus.git && cd Bot-WA-Nexus && npm install && npm start
